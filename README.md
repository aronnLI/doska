# SDK SMP — многостраничный сайт сервера

Статика на чистых HTML/CSS/JS в матовом «стеклянном» стиле: тёмный лес на фоне, полупрозрачные панели, один зелёный акцент. Без CMS, React и сборки — любой `.html` открывается двойным кликом.

```
index.html      — первый экран, живой статус, тизеры «о сервере» и галереи
about.html      — о сервере, механики, команда, контакты
gallery.html    — спавн, хаб и фермы (3 группы), лайтбокс
join.html       — как попасть: стрим Twitch, 3 шага, правила
store.html      — редирект на join.html (магазин временно убран)
faq.html        — 8 вопросов
rules.html      — полные правила
offer.html      — оферта (шаблон, нужны реквизиты)
privacy.html    — политика обработки ПД (шаблон)
assets/css/style.css
assets/js/config.js   ← IP, адреса API и все ссылки
assets/js/app.js      — общий скрипт для всех страниц
assets/img/           — фон, 7 скриншотов, og.jpg, logo-128.png, favicon.png, apple-touch-icon.png
proxy/worker.js       — прокси для Cloudflare Worker
proxy/server.js       — прокси на Node без зависимостей
```

## 1. Что менять в первую очередь

`assets/js/config.js` — единственное место для данных сервера:

| Поле | Значение сейчас | Что указать |
|---|---|---|
| `server.name` | SDK SMP | название (шапка, герой, подвал, `data-server`) |
| `server.ip` | `213.152.43.51:25642` | реальный IP/домен |
| `server.version` | `26.3` | версия для отображения |
| `server.mode` | выживание | режим |
| `server.maxSlots` | 20 | слоты, если API не отдал |
| `server.launchDate` | `2026-09-15` | дата запуска мира |
| `api.proxy` | пусто | адрес прокси (необязателен: статус работает напрямую) |
| `links.telegram` / `links.discord` | пусто | каналы |
| `links.pay.*` | пусто | ссылки касс (ЮKassa / Т-Банк / СБП) |

Пустая ссылка = кнопка неактивна и показывает тост, а не уводит на битый адрес. Пока пусто, кнопки Discord/Telegram и «Купить» работают как подсказки.

Плейсхолдеры по остальным файлам:

- В каждом `.html` — `<title>`, `description`, `canonical`, `og:url`, `og:image` (сейчас `example.com`).
- `assets/js/config.js` → `sameAs` в JSON-LD лежит в `index.html`.
- `offer.html` и `privacy.html` — блоки «Укажите реквизиты…»: без них документы силы не имеют.
- Ники команды в `about.html` и тексты правил — демонстрационные; магазин временно убран.

Шапка и подвал продублированы на каждой странице (так надёжнее без сборки). Активный пункт меню — класс `is-active` + `aria-current="page"`.

## 2. Как устроен дизайн

- Фон на всех страницах: `bg.webp`/`bg.jpg` (спавн), фиксированный слой `body::before`, размытие всего 1 px и затемнение через `body::after`. Без параллакса.
- Матовое стекло: `rgba(18,28,23,.58)` + `backdrop-filter: blur(20px) saturate(135%)`, тонкая рамка `rgba(255,255,255,.1)`, радиус 22 px. На экранах ≤900 px blur падает до 10 px, ≤720 px — до 8 px.
- Один акцент — зелёный `#46e08a`; свечение только у акцентных кнопок.
- Шрифт — Manrope (один Google Font) с системным фолбэком. Для полностью офлайн-версии удалите три `<link>` на `fonts.googleapis.com` — останется системный стек.
- Контраст: основной текст `#eef5f0`, вторичный `#a9bdb2` на тёмном стекле — выше AA. Фокус-обводка `2px` акцентом, `prefers-reduced-motion` отключает анимации.

Пинг игрока из браузера измерить нельзя — на сайте его нет, чтобы не показывать выдуманное число.

## 4. Прокси (необязателен)

### Cloudflare Worker

1. Dashboard → Workers & Pages → Create Worker → вставить `proxy/worker.js`.
2. Variables: `MC_HOST=213.152.43.51:25642`, `PLAN_URL=https://plan.example.com`, `PLAN_SERVER=имя в Plan`, `ALLOW_ORIGIN=https://ваш-домен`.
3. Deploy → адрес `https://…workers.dev` вписать в `api.proxy`.

### Node 18+

```bash
MC_HOST=213.152.43.51:25642 PLAN_URL=https://plan.example.com ALLOW_ORIGIN=https://ваш-домен node proxy/server.js
# GET http://127.0.0.1:8787/status
```

Кэш 60 с, таймаут 3 с, CORS, ответ `{online, players:{online,max}, version, tps, plan, ts}`. Поле `tps` остаётся в ответе, но сайт его не показывает.

## 5. Скриншоты и картинки

В `assets/img/` — реальные кадры сервера: `spawn`, `spawn-air`, `hub-1…3`, `farm-1…2` (каждый в WebP и JPG). Исходники лежат в корне: `spawn-src.png`, `spawn-air-src.png`, `hub*-src.png`, `farm*-src.png`, `hero-source.png`. Старые `gallery-*.jpg` и `forest-hero.jpg` больше не используются — можно удалить.

- `gallery-1…6` — **парами** `.webp` + `.jpg` с одинаковыми именами (JPG — фолбэк).
- Размер 1200×800 (3:2); `hero` — 1600×900.
- Alt и подпись: `alt="…"` у `<img>`, `data-caption="…"` у кнопки `.shot`.
- Новый скриншот: скопируйте `<button class="shot">…</button>` в `gallery.html` — лайтбокс подхватит его сам.
- `og.jpg` 1200×630 — превью в соцсетях, текст на нём лучше перерисовать.
- Конвертация: squoosh.app или `ffmpeg -i in.png -vf scale=1200:-1 out.webp`.

## 8. Запуск

- Локально: откройте `index.html`. Копирование в буфер на `file://` может требовать разрешения браузера — на хостинге с HTTPS работает штатно.
- Хостинг: залейте все файлы в корень (Netlify, Vercel static, Timeweb, обычный shared hosting). Ссылки вида `about.html` работают без настройки; для «чистых» URL настройте rewrite `/about` → `/about.html`.
- HTTPS обязателен: `backdrop-filter`, буфер обмена и `showModal` ведут себя предсказуемо только в защищённом контексте.
